# Tic-Tac-Toe GUI Game 🎮

## 📌 Project Overview
A classic Tic-Tac-Toe (XO) game developed in Java, utilizing the **Swing** library to build an interactive Graphical User Interface (GUI). This project transitions a traditional console-based logic into a clean desktop application, applying core Object-Oriented Programming (OOP) and event-driven architectures.

## 🚀 Features & Implementation
* **Dynamic Grid Layout:** Built using a 3x3 `GridLayout` with responsive `JButton` components.
* **Smart Game Logic:** Implemented a 2D matrix verification system to check for rows, columns, and diagonal wins instantly.
* **Turn & State Management:** Alternates turns smoothly between X and O with real-time color indicators (Red for X, Blue for O).
* **Interactive Dialogs:** Displays custom win/draw alert messages upon game conclusion.

## 💻 Core Technologies
* **Language:** Java
* **GUI Framework:** Java Swing & AWT
* **Concepts:** Object-Oriented Programming (OOP), Event Handling (ActionListeners)
